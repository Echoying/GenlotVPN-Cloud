编写目的
接口文档旨在提供对外部调用方关于我们组织、用户、应用、角色、权限的接口信息和规范的全面了解。本文档将详细描述我们的接口，包括请求和响应的结构、参数、返回结果等内容。它将帮助调用方准确地理解和使用我们的接口，以便顺利进行系统集成和数据交互。

本接口文档致力于提供简洁、可读性强且易于理解的接口规范，以促进调用方与我们的系统之间的无缝集成和通信。
接口说明
本开发手册对该系统功能接口进行详细的描述，通过该指南可以对本系统有全面的了解，使技术人员尽快掌握本系统的接口，并能够在本系统上进行开发。
开发前提
贵公司的技术部门的开发、维护及管理人员，应具备以下基本知识：
		了解HTTPS协议等内容。
		了解信息安全的基本概念。
		了解计算机至少一种编程语言。
		https支持明文传输，请注意证书处理
	
	贵公司需要在我们这边配置一个应用，然后取出应用里面的id 和 secret ，用来获取access_token
	
	
	
	

	
数据模型
接口会统一以JSON格式返回，并统一返回code、message和data数据。调用方需要校验code是否为200，当code不为200时，表示接口调用报错，根据不同的code码返回错误信息。
{
  &quot;code&quot;: &quot;200&quot;,
  &quot;messages&quot;: &quot;OK&quot;,
  &quot;data&quot;: {
    ……
  }
}
