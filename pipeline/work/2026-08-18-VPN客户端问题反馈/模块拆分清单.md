## 风险识别

| 风险 | 影响 | 应对 |
|------|------|------|
| 未批 spec 就开写 | 返工 | AGENTS.md HARD-GATE |
| 做成 TAPD（评论/指派） | 范围爆炸 | 附件只限 3 张截图；无评论/指派 |
| 未登录上传被灌图 | 磁盘与带宽 | 按 IP 限流、单张 ≤400KB、只收 jpeg/png |
| 先上传未提交留下孤儿文件 | 文件服务残留 | 本期不写清理任务；Redis token 2 小时过期，提交只认未过期 id |
| 新增 MessageType 被当成改传输层 | 误升 S0 或漏 PHASE2 | 不改 TLS/Pin/帧；M2/M3 建议 S1，级别由人定 |
| 把客户端塞进自动验收 | 安全项被跳过 | M3 只走 PHASE2；`client-ref` 仅参考 |
| 未登录也可提交 | 垃圾数据、难以对上用户 | 必填账号 + 按 IP 限流 |
| 凭证入库或进对话 | 合规否决 | 环境变量 + 脱敏 |
