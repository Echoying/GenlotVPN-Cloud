# _shared — 跨功能

不属于某一次闭环的东西放这里：桌面协议 ADR、流水线踩坑、门禁总表、[申报证据索引](申报证据索引.md)、[客户端参考走查登录流程](client-ref-走查流程.md)。

## 分享材料

两套分享主题（同一项目，不同侧重）：

1. **超级 AI 个体：** [提纲](分享提纲-超级AI个体.md)、[40 分钟 PPT](分享-超级AI个体-40分钟.pptx) — 侧重一人+AI 的工作模式和六阶段流水线
2. **研发+AI 全栈交付：** [提纲](分享提纲-研发AI全栈交付.md)、[40 分钟 PPT](分享-研发AI全栈交付-40分钟.pptx) — 侧重后端工程师如何通过人机协作完成全栈交付

改 PPT 前脚本会把上一版拷到 `share-ppt-bak/`（pptx 不入库）。

生成脚本：
- `build_share_pptx.py` — 生成「超级 AI 个体」版本
- `build_share_pptx_fullstack.py` — 生成「研发+AI 全栈交付」版本

某次功能自己的 spec / 计划 / 截图不要放进来。
