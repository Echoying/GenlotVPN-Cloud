# ADR-005：客户端登录走查沉淀到 _shared（2026-08-16）

| 项 | 内容 |
|----|------|
| 状态 | 已落地 |
| 范围 | `accept.py client-ref`、`accept_client_ref.py` |
| 触发 | 最低客户端版本拦截：命令写了，登录步骤只在对话里 |

## 决策

客户端 AI 基础走查的**登录怎么跑**写进 [client-ref-走查流程.md](client-ref-走查流程.md)，不靠聊天记录。脚本实现坐标、清空密码、找登录按钮、已登录先退出、管理端等 loading。当次 spec 第 7 节只写场景差异和可复制命令。

仍是参考走查，不等于 PHASE2 通过。不改客户端源码凑自动化。
