# ADR-006：客户端下载站放在 93，独立 nginx，443

## 背景

需要把易安联 SDK 与 GenlotVPN 客户端发给内网和出差用户。92 无对公网口；93 已有桌面端使用的公网 IP（机房地址池中的一个，**不是**官网 IP）。

## 决策

- 下载站放 **93**，**新起静态 nginx**，与 `ruoyi-vpn-auth` 分离。
- 本机听 **443**（HTTPS）和 **80**（只 301 到 HTTPS）。网络把 **该公网 IP 的 443/80** 映到 93 对应端口。**不占用**官网或其它机器的 443。
- **不共用** 9443（TLS+Protobuf）和 9400（vpn-auth HTTP）。
- 路径前缀 `/genlotvpn/`。证书放 93 本机，不进 Git；纯 IP 可用自签，浏览器告警可点继续。
- 发版：包进仓库 `apps/`，`deploy.py vpn` 扫目录写清单并同步。

## 未选

- 挂 92：管理端与下载包同机，且 92 不对公网。
- 下载走 Java / 文件服务：大包不合适，本期免登录。
- 与 9443/9400 同口：协议或暴露面错误。
