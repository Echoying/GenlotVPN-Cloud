# ADR-004：流水线收拢到 pipeline/

| 项 | 内容 |
|----|------|
| 状态 | 已落地 |
| 日期 | 2026-08-16 |
| 范围 | 仓库内流水线文档、脚本、Cursor 约定、本机凭证模板、本项目落盘 |

## 决策

流水线全部放在 `pipeline/`。通用入口在 `pipeline/bin/`，方法文档在 `pipeline/docs/`，Cursor 源在 `pipeline/cursor/`。本项目业务放在 `pipeline/work/`：`bin/` 是适配器，`_shared/` 是跨功能 ADR/门禁总表，**每一次闭环**用 `YYYY-MM-DD-短标题/` 单独放 spec / 计划 / 门禁 / 验收。移植时整夹替换。

根目录只留 Cursor 必须认的位置：`AGENTS.md`、`.cursor/rules`、`.cursor/hooks.json`。正式命令是 `python pipeline/bin/gate.py`，不再以 `bin/*.bat` 或 `docs/work/` 为入口。

## 后果

- 凭证可读 `pipeline/deploy/envs.yaml` 或仍用 `.deploy/envs.yaml`。
- 改 Rule 先改 `pipeline/cursor/rules/`，再同步到 `.cursor/rules/`。
- Hook 由 `.cursor/hooks.json` 调用 `pipeline/cursor/hooks/`。
- `gate` / `deploy` / `accept` 都应带 `--run`：结果写入当次 `质量门禁.md` 的「脚本记录」。`accept` 缺 `--run` 直接失败；报告只写入当次 `验收报告/`。
