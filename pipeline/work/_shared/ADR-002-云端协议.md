# ADR-002：桌面端与云端认证协议

- 日期：2026-08-15
- 状态：已采纳
- 背景约束：管理端继续走 HTTP；桌面端不能明文跑登录；厂商本地控制器 `127.0.0.1:30303` 保持 HTTP

## 备选方案

| | 优点 | 风险 |
|--|------|------|
| A. 桌面端继续 HTTP JSON（与网页同协议） | 实现快、可复用网关 | 抓包可见业务载荷，生产不可接受 |
| B. TLS 1.3 + TCP + Protobuf，端口 9443 | 密文传输、字段契约、与网页入口分离 | 两端要共用 `.proto`，调试比 JSON 重 |

## 决策

选 **B. TLS 1.3 + TCP + Protobuf（`ruoyi-vpn-auth` :9443）**。本地 30303 仍 HTTP。

## 否决

桌面端继续走 HTTP JSON：生产抓包会暴露密码/业务，过不了 S0。

## 安全影响

**S0**。生产默认 TLS，无明文 TCP fallback；证书 Pin 错误拒绝连接；密码/Token/`session_key` 不进日志。

## 复验方式

对照 PHASE2 的 S-xx：抓包 9443 为 TLS 密文；Pin 错误断开。人勾清单，不用 Playwright 代替。
